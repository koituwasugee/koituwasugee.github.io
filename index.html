ZundaKuizu について

ZundaKuizu は、このチャンネルの運営者が自分のチャンネルに動画を投稿するためだけに使う管理ツールです。YouTube API Services を利用します。一般の利用者向けには公開していません。

ZundaKuizu is an internal tool used only by the operator of this channel to upload videos to their own YouTube channel through the YouTube API Services. It is not offered to the public.
