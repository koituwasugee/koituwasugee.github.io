ZundaKuizu について

ZundaKuizu は、このチャンネルの運営者が自分のチャンネルに動画を投稿するためだけに使う管理ツールです。一般の利用者向けには公開していません。

ZundaKuizu is an internal tool used only by the operator of this channel to upload videos to their own YouTube channel. It is not offered to the public.

YouTube API Services を利用しています

ZundaKuizu は YouTube Data API v3 を使って動画を投稿します。利用にあたっては YouTube 利用規約と Google プライバシーポリシーが適用されます。情報の扱いはプライバシーポリシーをご覧ください。

ZundaKuizu uses the YouTube API Services (YouTube Data API v3). YouTube Terms of Service · Google Privacy Policy · Privacy Policy
